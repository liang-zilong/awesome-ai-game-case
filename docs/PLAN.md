# Awesome AI Game Case 规划与页面构想（讨论稿 v0.3）

更新：2026-09-23。当前是供你过目的本地草稿，没有发布到 GitHub 或部署到正式站点。

## 产品定位

为 AI 参与制作或驱动玩法的游戏做一个可玩、可追溯的目录。首页像 [Jevable](https://jevable.com/) 一样以真实图片或视频画面引导浏览。可玩游戏的主操作是直达游戏；没有公开可玩版本的 X 案例清楚标为“展示”，主操作直达原帖。每条案例都说明玩法、AI 角色、来源和核对日期。对公开信息不足的项目明确显示“AI 用途待核实”。

## 两个独立工程

| 工程 | 本地目录 | 职责 |
| --- | --- | --- |
| 公开内容库 | `awesome-ai-game-case/` | README、双语案例 JSON、封面/截图、收录与 X 采集规范、SEO 规划；未来可单独传 GitHub 作为外链 |
| 前端网站 | `awesome-ai-game-case-web/` | Next.js 静态页面、shadcn/ui 组件、交互、Cloudflare Workers Static Assets 配置；未来单独仓库 |

内容库为唯一编辑入口。网站构建前运行 `npm run sync:data`，复制已经审核的 JSON 和媒体资源。两边各有独立 Git 历史。访客浏览时没有数据库、X API 或 GitHub API 依赖。

## 内容规则

- **平台**：`mobile`、`web`、`pc`，可以多个；指实际游戏可运行的平台，不把 X/itch/Steam 当成平台。
- **玩法类型**：一个主类型，动作、休闲、益智、赛车、射击、体育、策略、模拟、冒险、生存、角色扮演；难以确定用 `other`。可在未来增加标签，但不能用标签冒充已核实玩法。
- **收录门槛**：有真实游戏媒体，以及游戏直达地址或作者 X 原帖。暂不收录只有商店页、平台介绍页或抽象占位图的项目。
- **AI 证据**：区分 AI 辅助开发、素材、运行时玩法。作者未说明时标“待核实”，不猜测。
- **X**：保留原帖地址、作者、时间、原文、媒体及展开后的外链；机器人输出是候选数据，人工核对后才发布。详见 [X 采集规范](X_COLLECTION_SPEC.md)。
- **媒体**：优先作者官网分享图、原帖视频海报或实际游戏截图。卡片均应显示画面并写 alt；在详情页保留媒体来源。当前截图和海报在内容库 `media/cases/`，构建时同步到网站。
- **发布前媒体核对**：当前草稿保存了来源截图与公开海报以便视觉审核；正式公开前确认对应素材的转载条件，不合适的改为获许可图片或自行截取的编辑性画面。

## 页面设计

- **首页**：大标题、真实媒体卡片墙、平台和类型筛选、搜索、玩法类型入口、简短 FAQ、收录方式。卡片有画面、标题、介绍、玩法类型、状态、直达按钮；有 X 原帖则展示 X 链接。
- **案例详情**：稳定的 `/games/[slug]/`，清晰的 H1、封面、概要、玩法、AI 用途、来源、平台、类型、作者、可玩/展示状态；可玩按钮在首屏。可嵌入网页游戏支持主动点击预览，遇到禁止嵌入时仍可直达原站。
- **类型页**：`/genres/[genre]/`，每个已收录的类型静态生成独立正文与案例列表，支持搜索意图和内部链接；空类型不生成。
- **FAQ**：`/faq/` 解答在线玩、展示与可玩区别、AI 用途、预览限制、X 审核和提交方式。
- **多语言**：英文 `/` 为默认；中文 `/zh-CN/`。详情、类型和 FAQ 全部有对应语言页面，切换语言保留当前主题。

视觉方向：明亮背景、深绿主色、轻量边框、媒体占据卡片上半部；参考 Jevable 的画面优先布局，但页面文案和行为围绕“打开游戏”。使用 [shadcn/ui 官方 Next.js 方案](https://ui.shadcn.com/docs/installation/next)的 Button、Card、Select、Dialog 等组件。网站工程内另有 `docs/design-v1.html` 视觉草图与本地可运行页面供审核。

## 技术与上线前核对

网站使用 Next.js App Router 静态导出、Tailwind、shadcn/ui。已安装 Cloudflare Wrangler CLI，部署配置在网站工程。当前 `SITE_URL` 使用本地地址构建；正式发布前必须换成最终域名，否则 canonical、Open Graph 与 sitemap 会指向本地地址。正式部署与 GitHub 发布留待你看过页面后决定。

当前验证：`npm run lint` 与 `SITE_URL=http://localhost:8787 npm run build` 通过，36 个路由静态生成。还需要在正式域名上检查游戏 iframe 是否允许嵌入；当前受控浏览器内部分目标 iframe 可能显示空白，直达链接可以使用。详见 [SEO 计划](SEO_PLAN.md)。
